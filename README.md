# UnReal World — перевод 0.47

Для UnReal World 3.89.1 на Windows. Русский и финский перевод, оригинальный английский через лаунчер.

В 0.47 добавлен отдельный журнал запуска и ошибок и кнопки **«Показать лог» / «Скопировать лог»**. Для сообщения об ошибке запуска нажмите «Скопировать лог» и вставьте текст в сообщение. Игровые тексты и действия в этот файл не записываются. DLL и переводы сохранены из 0.46, включая предыдущие исправления.

Нажмите **«Проверить обновления»** в лаунчере либо скачайте **Hook_0.47.zip** из [Releases](https://github.com/Librianets/UnRealWorld_Translation/releases/latest) и распакуйте рядом с urw.exe с заменой файлов перевода. Лаунчер тоже обновляется. При включённом запуске через Steam затем нажмите **«Обновить загрузчик Steam»**.

Оригинальная игра и сохранения не входят в архив. Подробности — [steam.txt](steam.txt). Source code на странице выпуска не является установочным пакетом. Полный игровой охват перевода не заявляется.
