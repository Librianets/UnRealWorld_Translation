# UnReal World — перевод 0.46

Для UnReal World 3.89.1 на Windows. Русский и финский перевод; оригинальный английский доступен в лаунчере.

В 0.46 исправлен пропуск перевода подписи местности на локальной карте, включая «Coniferous forest at Risupää "Twighead"». Исправление запуска на чистой установке из 0.45 сохранено.

Из 0.44 включены исправления составных ошибок имени, подписей Near, слухов о проступках, возврата вещей и финской формы одной минуты.

**Обновление с 0.43:** закройте игру, откройте URW_Launcher.exe и нажмите «Проверить обновления». Ошибка запуска игры не мешает обновлению лаунчера.

Для установки вручную скачайте **Hook_0.46.zip** из [Releases](https://github.com/Librianets/UnRealWorld_Translation/releases/latest), распакуйте рядом с urw.exe и запустите URW_Launcher.exe. Если включён запуск через Steam, выполните предложенное обновление загрузчика при закрытой игре.

Переводы и шрифты встроены в DLL; внешние каталоги не требуются. Игра и сохранения в архив не входят. Подробности — [steam.txt](steam.txt). Source code на странице выпуска содержит описание репозитория, а не установочный пакет.

Полнота перевода всех игровых ситуаций не заявляется. Неточности: скриншот, исходный текст, версии игры и патча — librianets@gmail.com.
