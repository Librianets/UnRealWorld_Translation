# UnReal World — перевод

Версия **0.43** для **UnReal World 3.89.1**, Windows 10/11.
Языки: русский и финский; оригинальный английский доступен в лаунчере.

Готовый комплект находится в [Releases](https://github.com/Librianets/UnRealWorld_Translation/releases/latest).
Откройте **Assets** и скачайте **Hook_0.43.zip**. Архивы **Source code** не нужны для установки.

Закройте игру, распакуйте содержимое ZIP рядом с `urw.exe` и запустите `URW_Launcher.exe`.
Выберите ENG/RUS/FIN. Кнопка «Проверить обновления» загружает следующие версии из этого репозитория.
Для первого перехода с 0.30 и ниже распакуйте 0.43 вручную; далее обновления встроены в EXE, без PowerShell.
Если ранее включали запуск через Steam, после замены файлов при необходимости обновите загрузчик в лаунчере.

Перевод и шрифты находятся внутри DLL. Каталоги JSON/CSV, редактор, запись игровых сообщений и Launcher Plus в этот комплект не входят.
Игра приобретается отдельно; оригинальный игровой EXE в архив не включён.

Неточный или отсутствующий перевод: пришлите скриншот либо текст и место его появления, версии игры/перевода на librianets@gmail.com.
Подробная инструкция: [steam.txt](steam.txt).

Лицензия собственного кода 0BSD не распространяется на игровые тексты, переводы, шрифты и сторонние библиотеки; см. `LICENSE_SCOPE.txt` и лицензии в комплекте.
